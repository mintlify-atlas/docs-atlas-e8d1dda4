Amrutam is a production-ready telemedicine backend built on FastAPI, PostgreSQL, and Redis. It handles the full clinical workflow — from patient registration and doctor slot booking through consultation management, sealed prescription generation, and payment processing — with enterprise-grade security and observability built in from the ground up.

## Stack at a glance

| Layer | Technology |
|---|---|
| API framework | Python 3.11 / FastAPI + Uvicorn |
| Primary database | PostgreSQL 16 (partitioned tables) |
| Read replica | PostgreSQL 16 (search + analytics) |
| Cache / streams | Redis 7 |
| Object storage | MinIO (S3-compatible) |
| Edge / LB | Nginx (TLS, rate limiting, health eviction) |
| Observability | OTel Collector → Prometheus / Loki / Tempo → Grafana |

<Note>
  The API is versioned under `/v1`. All authenticated endpoints require a `Bearer` token in the `Authorization` header obtained from `POST /v1/auth/login`.
</Note>
